# PariCerise.github.io

This repository now contains a simple one-page GitHub Pages website for Paricerise with:

- hero section and brand styling
- menu cards for fruit leather and jams
- campus pickup order form
- responsive design for mobile and desktop
- WhatsApp order generation in JavaScript

Files created:
- `index.html`
- `styles.css`
- `script.js`

Notes:
- Update the WhatsApp number in `script.js` before publishing if you want real order messages.
- Update contact details and pricing in `index.html` as needed.
- If GitHub Pages is not enabled yet, enable it in the repo settings under Settings > Pages and choose the main branch.
