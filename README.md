# PariCerise v4 — image-led redesign

A simplified, photo-led GitHub Pages site for PariCerise.

## What changed
- Reduced text and visual clutter
- Smaller heading sizes and calmer typography
- Larger food/lifestyle images
- Simplified product cards
- Kept basket + WhatsApp ordering
- Berry red `#CC3333` with sage/pistachio green

## Before launch
- Replace the placeholder WhatsApp number in `script.js`
- Confirm prices and package weights
- Replace generic ingredient/lifestyle images with your own product photography when available
- Update Instagram/email details if needed
